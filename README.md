# پلتفرم آموزشی پولاریس (Polaris Educational Platform)

زیرساخت معماری و سیستم طراحی اولیه پلتفرم آموزشی پولاریس با استفاده از Vite، TypeScript و CSS خالص.

## دستورات پروژه

### نصب وابستگی‌ها
```bash
npm install
```

### اجرای محیط توسعه (Dev Server)
```bash
npm run dev
```

### بررسی تایپ‌ها (Type Check)
```bash
npm run typecheck
```

### ساخت نسخه تولیدی (Build)
```bash
npm run build
```

### پیش‌نمایش نسخه تولیدی (Preview)
```bash
npm run preview
```
