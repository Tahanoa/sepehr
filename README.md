# سپهر | Sepehr Educational Platform

سامانهٔ نمونهٔ مدیریت آموزش با Vite، TypeScript و Tailwind CSS.

## بازطراحی و ظاهر قابل تغییر

- سه تم سبز سپهر، آبی اقیانوس و ارغوان
- رنگ اصلی و تأکیدی سفارشی همراه با بررسی خوانایی
- انتخاب فونت، تراکم و میزان گردی گوشه‌ها
- پیش‌نمایش زنده، ذخیرهٔ محلی و ورود/خروج فایل JSON
- پیش‌خوان دانش‌آموز با تکالیف و آزمون‌های مرتبط با همان کلاس
- هویت فارسی سپهر، بهبود پنل مشترک و مدیریت فوکوس مدال

تنظیمات ظاهر از دکمهٔ «ظاهر» در هدر پنل و بخش تنظیمات مدیر قابل دسترسی است. تنظیمات فعلاً مخصوص همین مرورگر هستند؛ نسخهٔ فعلی بک‌اند احراز هویت و ذخیرهٔ برند سازمانی ندارد.

## اجرا و بررسی

```bash
npm ci
npm run dev
npm run typecheck
npm run build
npx playwright install chromium
npm run test:ui
```
